## The One-Minute Version

**Agile** = A mindset: Build in small pieces, get feedback, adapt, repeat.

**Scrum** = A framework: Use Sprints (2 weeks), Daily Standups, backlogs, and ceremonies to make Agile work.

**Sprint** = A 2-week time box where your team plans, builds, and delivers one piece of the product.

**Backlog** = Your to-do list, organized by priority.

**User Story** = One feature written from the user's perspective (e.g., "As a user, I want to log in so I can access my account").

**Task** = The technical work needed to build the story (e.g., "Create login form", "Add password validation").
